# Nexo Media — Landing Page

Landing oficial de **Nexo Media** (Marketing Agency | Growth Business).
Solo HTML + CSS. Sin JavaScript ni dependencias.

## Estructura

Todos los archivos van juntos en una sola carpeta. Sin subcarpetas.

```
index.html                     → página completa
styles.css                     → todos los estilos y animaciones
logo.png                       → logo oficial
resultado-ecommerce.webp       → captura Meta Ads (ecommerce, 1 mes, Colombia)
resultado-conversaciones.webp  → captura Meta Ads (negocio físico, 1 mes, Colombia)
```

Importante: los 5 archivos tienen que quedar en el mismo lugar que `index.html`,
con esos nombres exactos. Si los metes en carpetas, la página no encuentra el logo,
las capturas ni los estilos.

## Cómo publicarla gratis con GitHub Pages

1. Crea un repositorio nuevo (por ejemplo `nexo-media`).
2. Sube los 5 archivos de este paquete tal cual, todos juntos en la raíz
   (arrastra `index.html`, `styles.css`, `logo.png` y las dos capturas `.webp`).
3. Ve a **Settings → Pages**.
4. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
5. En 1–2 minutos tu landing queda en línea en
   `https://TU-USUARIO.github.io/nexo-media/`
